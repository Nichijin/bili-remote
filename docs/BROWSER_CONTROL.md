# Edge / Chrome 控制方式 · 0.5.10

[项目首页](../README.md) · [使用指南](USAGE.md) · [常见问题](FAQ.md)

普通浏览器的系统媒体会话和专用窗口的网页接口是两种控制方式。0.5.10 会显示最近确认的实际目标，避免把后台 Edge 的成功操作误认为正在看的 Chrome 已被接管。

![手机连接与设置示例](images/mobile-connection.png)

| 使用方式 | 暂停 / 进度 | 视频音量 / 长按倍速 | 选择方法 |
| --- | --- | --- | --- |
| 手动打开的普通 Edge / Chrome | 取决于 Windows 媒体会话实际开放能力 | 系统接口无单视频音量；倍速取决于实际开放能力，不保证支持 | 手机“系统媒体 / 客户端”→“检测浏览器 / 客户端”→选对应会话 |
| 软件主动打开的 Edge / Chrome 专用窗口 | 网页视频接口 | 支持本项目的视频音量与临时倍速流程，具体视频仍受播放器状态约束 | 选择浏览器后点击“在电脑打开哔哩哔哩” |

## 保持普通浏览器播放

先播放视频，再检测会话。选项会显示实际提供的暂停、进度、倍速能力。Chrome 和 Edge 使用相同检查规则，不根据品牌推断能否完整控制。

如果接口没开放倍速，会明确报错，软件不会转去操作另一窗口。如果浏览器没有提供系统媒体会话，或者同一浏览器多个播放会话使用相同应用标识，软件无法可靠区分；请只保留一个播放标签页，或主动使用专用窗口。

普通浏览器系统媒体接口的音量是应用音频通道，可能同时影响其他标签页。本版不使用它替代单视频音量，调音量时会提示使用专用网页。

## 使用完整网页控制

手机“设置 → 播放器 → 打开网页时使用”选择 Edge 或 Chrome，再点击“在电脑打开哔哩哔哩”。成功后自动切到专用网页控制。在新窗口中打开视频，核对“最近确认目标”显示的浏览器名称。

电脑端连接页提供相同的浏览器选择。选择 Chrome 不会改成 Edge；未安装所选浏览器会明确报错。Edge 和 Chrome 分别保存资料，原 Edge 资料不搬迁；Chrome 第一次需要单独登录。

![电脑连接页示例](images/desktop-main.png)

只有主动点击打开入口才会启动窗口。普通遥控操作、配对、切换菜单和更换浏览器选项都不会自动打开视频或重启普通浏览器。完全退出电脑端会关闭其管理的专用窗口，普通窗口不受影响。

## 自动选择如何避免误控

- 前台是浏览器时，核对进程与可见视频。无法确认该视频时停止，不落到另一个后台专用窗口；同品牌不同进程也不能绕过此检查。
- 普通浏览器自动匹配需要本机哔哩哔哩窗口与媒体标题相符。媒体接口不提供可靠的标签页 URL，因此无法确认时使用明确选择，不保证每个网页都自动识别。
- 同时存在多个活动候选时要求手选。隐藏且暂停的专用页面不会只因进程存在就获选。
- 长按开始后绑定原控制器和媒体会话，换挡及松手不重新选目标。进度拖动继续校验视频标识，目标变化会停止。

“最近确认目标”表示上次成功操作或主动打开确认的通道，属于历史状态，不是对所有浏览器的实时追踪。电脑操作记录也会包含该目标；失败时请结合错误文字判断。

## 验证范围

已用隔离的本地视频分别验证 Edge / Chrome 的暂停、连续进度、视频音量、临时倍速、换挡和恢复；自动路由、同品牌不同进程、多个目标、能力拒绝、固定长按目标及手机选择界面均有回归检查。

没有用测试操作用户正在播放的视频。自动匹配依赖系统媒体信息和窗口证据，各浏览器版本、网页状态及多窗口情况仍有差异；本版不承诺所有普通标签页无需网页接口即可完整控制。
