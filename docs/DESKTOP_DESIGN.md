# 电脑端设计说明

[项目首页](../README.md) · [使用指南](USAGE.md) · [设计参考](DESIGN_REFERENCES.md)

本说明记录 0.5.8 已实现的界面与交互决策。参考 Apple Human Interface Guidelines 的信息组织、直接操作、反馈和适配原则，并结合 Windows 的窗口、字体与键盘习惯实现。Apple 文档和系统设置参考图于 2026-10-22 实际打开查看；未使用 Apple 的图片、字体、图标或源代码作为软件素材。

## 1. 从任务确定页面

电脑软件承担连接服务、打开播放器、查看反馈和调整偏好四类任务。侧栏提供固定的四个入口：连接与播放、客户端与版本、操作记录、设置。导航顺序不随连接状态改变；选中项同时使用底色、图标和名称表示，Alt+1–4 可直接切换。窄窗口自动收起侧栏文字，图标悬停显示名称；小高度压缩次要留白，保留主要入口。

默认连接页优先呈现真实在线状态、电脑地址、首次配对码和打开播放窗口入口。未连接时不展示虚构的视频、音量或手机电量。手势操作仍由手机完成，电脑端不增加重复的播放按钮。

## 2. 布局和视觉层级

| 决策 | 实现与原因 |
| --- | --- |
| 稳定导航与独立内容区 | 浅灰侧栏区别于内容背景；改变设置不会挪动导航 |
| 使用完整可用宽度 | 页面铺满侧栏右侧区域，滚动内容同步铺满；取消固定 640 / 360 逻辑像素上限和居中列，只保留左右 14 个逻辑像素内边距 |
| 相同功能保持分组 | 连接、播放、最近操作分别成卡片；设置分通用、字幕、帮助与管理 |
| 使用对齐与留白建立关系 | 统一左边缘、卡片内边距、标题和说明间距，避免用大量分隔线或装饰色分割内容 |
| 宽窄布局保留全部功能 | 连接信息与配对码空间足够时并排，窄时上下排列；按钮行换行，内容可滚动 |
| 明确主次 | 页面标题、组标题、正文、次要说明形成层级；蓝色主要用于选中项、焦点和主要操作 |

页面整体采用浅灰背景、白色卡片和细边界。保留 Windows 原生标题栏、最大化、最小化和关闭操作。参考的是 Apple 的信息组织方式；毛玻璃、实时模糊或复杂透明层不适合本工具的轻量和响应速度要求，因此没有加入。

## 3. 字体、颜色与清晰度

使用 Windows 已有的 Microsoft YaHei UI / Segoe UI，正文保持常规字重，标题按字号与粗细区分层级。正文和说明色分别为深色与较深的灰色，避免浅灰细字。状态同时显示文字和颜色；失败操作有明确的失败标记和原因。

圆角、开关、滑块和线性图标按当前像素尺寸以 4 倍分辨率绘制，再使用 Lanczos 下采样，保留边缘覆盖率。卡片底图只生成一次并复用，按九宫格绘制；静止、切页及普通窗口缩放时不重新生成图片。边缘预先与实际背景混合，减少透明底图在 Windows 主题控件上的亮边。

程序声明 Per Monitor V2 DPI 感知，初始窗口按工作区与缩放确定尺寸。文字使用系统字体渲染，未把整页截图放大。100%、125%、150%、200% 字体缩放及多种窗口大小有自动化布局检查；真实跨显示器 DPI 切换仍需实机补测。系统字体平滑和显示器像素密度也会影响最终文字效果，不承诺所有环境完全没有锯齿。

## 4. 字幕设置：直接操作和持续反馈

![字幕编辑与持续预览](images/desktop-feedback.png)

字幕设置的页内预览持续展示样式。拖动示例字幕直接改变水平、垂直位置，不必反复猜测百分比。选中预览后可用方向键逐次调整 1%；位置预设和数值滑块仍可用于精确调整。

“在屏幕上拖动字幕”打开实际大小的持续预览，显示在主窗口所在显示器的工作区。预览不会像普通操作提示那样在 1.5 秒后消失；可以拖动到目标位置，再继续调整字号、文字颜色与透明度，屏幕与页内预览同步更新。页内画面用于位置和样式示意，实际字号与透明度以屏幕预览为准。

- 拖动限制在工作区内，支持负坐标显示器；位置以可移动范围的百分比保存。
- 修改自动保存，连续拖动合并磁盘写入；停止约 250 ms 后提交，关闭程序也会提交待保存内容。
- 按 Esc、“结束屏幕预览”、切到其他页面、最小化或关闭主窗口，会结束屏幕预览。关闭字幕总开关也会结束预览并禁止继续拖动。
- 正常遥控反馈仍短暂显示、不抢焦点并允许鼠标穿透；只有显式打开的编辑预览可拖动，避免平时字幕遮挡播放器操作。
- 保留颜色输入、系统颜色选择器、位置预设、滑块与恢复默认入口。输入不完整时保留上次有效样式。

## 5. 响应与绘制

0.5.8 取消页面上下滑动和菜单选中背景的过渡动画，直接显示预先布局的真实页面。页面不再分配整页分层纹理，也不升起中间遮盖层；控件、编辑值与滚动位置继续复用，后台页不参与 Tab 导航。保留白色圆角选中态、蓝色图标 / 加粗文字，以及鼠标与键盘焦点区分。

滚动内容在首次实际滚动时才申请缓存，并从已显示的真实控件同步完成首轮绘制，避免启动时把尚未绘制的分层窗口暴露为黑色。后续滚动仍只移动内容缓存，连续滚轮合并为约 100 ms 的短过渡；反向立即响应，滚动条和键盘翻页直接定位。首次滚动有缓存准备成本，不能把后续低耗时当作首次滚动耗时。

客户端列表按稳定身份更新发生变化的行，保留选中项和滚动位置；重复结果也结束“正在检测”提示。仅有浏览器、没有已安装客户端和现有媒体管理器时，避免初始化 WinRT 媒体 DLL；客户端控制依然按需加载。手动重新检测会刷新注册信息，切页使用缓存。

电脑安装器会展开运行依赖，启动时无需再次解压单文件包。仍只需下载一个安装器；安装后的 EXE 依赖同目录 `_internal`，不要单独移动 EXE。当前版本在本地显示，检查更新仅在首次进入版本页或手动触发时后台进行，详见[绘制、更新与复测](RENDERING.md)。

保留全宽适配、直接拖动字幕和持续预览。窗口尺寸 / 字体变化仍需重排，不能保证所有电脑绝对零延迟；未把重复渲染成本隐藏到点击后再创建页面。

## 6. 键盘、可发现性与可访问性

主要入口带文字；紧凑侧栏有悬停说明。Tab 只进入当前页，保留可见焦点；Alt+1–4 切页，Esc 结束字幕编辑，预览方向键微调。滑块、开关、输入框继续使用原有主题控件，禁用状态明确；不把整套设置画成无法交互的图片。

较大字体下允许换行和纵向滚动，不通过缩小文字强行塞入窗口。危险操作单独使用明确的卸载文字与颜色，连接失败保留原因和操作记录。尚未完成 Windows 屏幕阅读器的全面验证，不把键盘可用等同于完整辅助功能认证。
