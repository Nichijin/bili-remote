# 电脑端闪黑、绘制与性能 · 0.5.9

[项目首页](../README.md) · [电脑端设计](DESKTOP_DESIGN.md) · [开发说明](DEVELOPMENT.md)

0.5.8 没有彻底解决用户看到的闪黑。连续抓屏重新捕获到了切页时整块空白，以及未画完的页面；旧测试图也有菜单与内容不一致、设置与客户端文字混在一起的情况。只在切换后抓几张静止截图、判断黑色像素比例，会漏掉这些问题。

0.5.9 替换了电脑主界面的绘制层，删除 Tk 页面叠放、分层子窗口缓存及外部 HWND 位移。主界面改用 Qt Widgets 的统一光栅双缓冲，没有加入网页内核、OpenGL 场景或切页动画。服务协议、配对及用户设置保持兼容。

![当前界面与版本入口](images/desktop-players.png)

## 发生了什么

旧界面由大量独立原生子窗口组成，每个控件分别处理绘制；滚动又绕过 Tk 几何管理器直接移动 HWND，并为内容增加分层缓存。Tk 控件树、原生窗口坐标、分层表面与页面前后顺序因此需要共同保持同步。把缓存创建推迟、移除动画，只减少部分触发机会，没有消除这套混合状态。

本轮 A/B 测试中，旧实现出现短暂整块空白；仅关闭分层缓存或改成单一可见 Tk 页面，仍能采到控件分批出现的中间画面。主窗口强制 WS_EX_COMPOSITED 的试验还导致绘制事件循环不结束，因此没有作为发布修复。

Qt Widgets 在顶层窗口的同一 backing store 中绘制普通子控件，QStackedWidget 负责只显示当前页，QScrollArea 统一处理裁剪、坐标与滚动。主界面原生后代窗口数由旧测试中的 146 个降为 0；四页仍提前构造且保留状态，字幕作为独立的被动顶层窗口按需创建。

这是对已复现绘制路径的更换，不代表已经定位所有电脑上每一次闪黑的唯一原因。

## 测量方法与结果

连续观察使用独立线程 MSS 抓取实际屏幕；导航时不调用 PrintWindow、DwmFlush 或强制重绘。每帧与完整页面参考比较，平均 RGB 误差超过 2/255 时标记为中间画面，同时检查大面积黑色。采样跨操作边界和最小化系统动画分开标记，避免把桌面背景当成软件黑屏。滚动另做先抓屏、后完整更新的对照。

同机首轮旧版 40 次切页、450 个样本捕获到 16 个中间画面；新版后续 160 次切页、千余个样本未捕获到黑帧或中间错绘，抓屏间隔中位约 14 ms；各轮峰值见性能附件。新增最终 EXE、真实鼠标、托盘恢复、窗口缩放及覆盖升级检查，原始结果随 `Performance-0.5.9.json` 发布。

| 指标 | 0.5.8 基线 | 0.5.9 首轮测量 |
| --- | ---: | ---: |
| 实际 EXE 到窗口可见中位数 | 约 645 ms | 约 280 ms |
| 连续屏幕采样场景的切页处理中位数 | 8.571 ms | 约 2–3 ms |
| 服务在线、主窗口显示的工作集 | 约 49 MiB | 约 80 MiB |
| 相同条件的私有内存 | 约 31 MiB | 约 41 MiB |
| 运行进程 | 1 | 1 |

Qt 增加了运行库体积与内存；本次工作集约增加 30 MiB、私有内存约增加 11 MiB。没有裁剪工作集或用隐藏窗口冒充可见窗口内存。内存按每版启动 3 次、服务在线等待 5 秒后采样 6 次取中位数，包含程序全部进程，没有手机或播放器负载。

窗口缩放首轮 Qt 源码处理中位约 7 ms、最大约 12.5 ms；旧版此前约 1 秒。新的同参数基线和最终结果记录在性能附件中。两个框架的逻辑像素定义不同，连续切页比较使用相同物理窗口大小，其余源码交互测试报告具体场景，不混称为光学呈现延迟或所有电脑的体验。

129 项 Python、35 项 Node 回归检查，以及 8 种逻辑尺寸 × 4 个 Qt 缩放因子布局检查通过。图文配图属于独立示例状态，不作为网络或实际手机测试证据。

## 当前版本和更新

“客户端与版本”直接显示构建内 `APP_VERSION`。首次进入时后台查询 GitHub 最新正式版与本仓库对应安装包；缓存约一小时，支持 ETag 与手动强制刷新，API 受限时使用官方发布网页备用路径。离线明确显示失败，允许重试。网络只写结果队列，不阻塞界面；不会自动安装或重启。

## 安装和复测

运行 `BiliRemote-Setup-0.5.9.exe` 直接覆盖旧版，保留配对和设置；电脑无需额外安装 Qt 或 Python。安装后的 EXE 依赖同目录 `_internal`，不要单独移动。已有 0.5.0 或更新安卓端可继续使用。

复测命令见[开发说明](DEVELOPMENT.md)。GUI / 浏览器 / 性能检查顺序执行，使用独立身份、数据目录和端口，不操作正式安装、用户浏览器或播放内容。

有限抓屏只能说明记录到的帧；约 14 ms 采样仍可能漏掉更短的瞬时变化。当前环境没有验证其他显卡 / 驱动、多显示器实际 DPI 切换、实体安卓安装及全部哔哩哔哩客户端，不能宣称所有环境绝不闪烁。
