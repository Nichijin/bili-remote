# 哔哩哔哩遥控器 0.4.1

手机遥控电脑上的哔哩哔哩。安卓端提供传统遥控器和纯黑触摸板两种样式，电脑端无需安装浏览器扩展。

## 安装与连接

1. Windows 10 1809 或更新的 64 位 Windows：安装 `dist/BiliRemote-Setup.exe`，打开电脑端。无需安装 Python。手机安装 `dist/bili-remote-debug.apk`，需要 Android 8 或更新版本。
2. 手机与电脑连接同一路由器；电脑使用网线也可以。Windows 防火墙首次提示时，允许程序在专用网络访问。
3. 电脑端在线时定时广播；手机打开后自动扫描。首次连接，在手机输入电脑端显示的 6 位配对码即可，无需再到电脑上点击允许。
4. 配对后保存独立授权，下次直接自动连接。电脑 IP 变化时，手机通过稳定的电脑标识寻找新地址；多台电脑时选择目标。配对码每 10 分钟刷新，已配对手机不受影响。
5. 自动扫描不可用时，在手机设置的“手动输入 IP / 连接记录”里填写地址，点击“连接并保存地址”。记录会保留，可点选重连或删除。Android Studio 模拟器访问宿主电脑可使用 `10.0.2.2:8765`。

电脑端“取消手机授权”会断开已连接手机，下次需要重新输入配对码。旧版的电脑点击允许流程已被配对码替代，两端建议同时更新；之前已授权的手机凭据继续有效。

## 覆盖升级

**电脑和手机均直接安装新版，不要先卸载旧版。** 卸载属于清除数据的操作，与升级不同。

- Windows：运行新版 `BiliRemote-Setup.exe`，自动识别并沿用旧安装目录，在原位置替换程序，保持一个安装登记。运行中的电脑端会先正常退出，安装成功后恢复到托盘，手机可自动重连。升级期间遥控会短暂断开，专用播放窗口会关闭，升级后可重新打开播放。
- 电脑设置、手机授权、电脑标识和专用浏览器资料保留；自启选项读取当前实际状态，包括用户后来在软件或任务管理器里的修改；桌面快捷方式的选择也会保留。可以安装同版本修复程序，新安装器会拒绝降级到较低版本。重新安装不等于重置设置。
- Android：打开新版 APK，按系统提示确认“更新”。固定包名、沿用旧版签名且递增版本代码，保留手机标识、配对凭据、手动 IP 记录和遥控器样式。无须重新配对，不需要清除应用数据。系统的安装确认不能由普通 App 绕过。
- 若手机提示签名冲突，不要先卸载：需要使用与已安装版本一致的密钥重新构建。自行用 Android Studio 默认密钥构建过的旧版，可能与这里发布的签名不同。浏览器资料保留不代表哔哩哔哩登录会话永不过期。

本次已用隔离安装身份验证 Windows 0.4.0 到 0.4.1 的覆盖流程；Android 已检查旧、新 APK 的包名、签名和递增版本代码，尚未进行实体手机覆盖安装验证。

## 无扩展播放

**网页视频：在电脑软件点击“打开哔哩哔哩 · 无需扩展”，然后在打开的窗口中选择视频。** 手机的传统遥控器也提供打开电脑哔哩哔哩的入口。

软件复用已经安装的 Edge 或 Chrome，自动建立可遥控的播放窗口，不需要扩展、不需要手动设置调试端口，也不捆绑浏览器内核。首次遥控操作也会尝试打开窗口；主页没有视频时会提示先选择视频。

此播放窗口使用独立浏览器配置，因此可能需要重新登录一次哔哩哔哩。登录保存在电脑端私有数据目录中，退出电脑端会关闭该专用窗口，不会关闭用户平时使用的浏览器。网页完整控制只作用于软件打开的播放窗口，普通浏览器窗口的现有标签页无法保证直接受控。

**Windows 客户端：直接打开客户端播放即可。** 手机默认自动选择：已打开软件的遥控播放窗口时优先该窗口，否则选择已发现的哔哩哔哩客户端；也可在设置中明确选择网页或客户端。多个客户端时可检测并选择媒体会话。暂停、进度和倍速等能力取决于客户端实际提供的 GSMTC 接口，无法保证各种版本均支持全部功能；不支持时会在两端报错，不会伪装成功。

## 两种遥控样式

在手机设置中选择样式，自动记住上次选择。现有用户默认保留触摸板；传统遥控器底部可直接切换回触摸板。

| 操作 | 触摸板 | 传统遥控器 |
| --- | --- | --- |
| 播放 / 暂停 | 任意位置轻点 | 中央播放键 |
| 音量 | 上滑 / 下滑 | 音量 + / −，每次 5% |
| 快进 / 快退 | 右滑 / 左滑，松手跳转 | 左右按键，每次 10 秒 |
| 临时倍速 | 长按 0.5 秒 | 按住倍速键 |
| 恢复原速度 | 松手 | 松开倍速键 |
| 打开设置 | 双指触摸，或 Android 返回键 | 右上角设置键，或返回键 |

横向滑动一个屏幕宽度对应 120 秒，单次最多跳转 120 秒；倍速可设置 1.5 / 2 / 3 / 4。恢复的是按下前的原速度，例如原本 1.5 倍，松手恢复 1.5 倍。

触摸取消、样式切换、进入后台、断线和心跳超时都会释放临时倍速。网页和电脑端均有恢复机制；播放器拒绝恢复时会报错并重试。播放器进程被强制终止或页面已销毁时无法继续调用旧播放器接口。

## 电脑反馈与设置

- 每次遥控会显示短暂桌面提示，包含暂停、跳转、音量、倍速及失败原因。提示不激活窗口、不抢播放器焦点。“连接与播放”页也显示最近操作，“操作记录”页保留本次运行最近 100 条操作。可在设置中关闭桌面提示。
- 开机自启默认关闭，可在设置页切换；自启后隐藏到系统托盘。最小化和关闭窗口默认保留后台运行，双击托盘恢复、右键退出；关闭行为可配置。重复打开会唤回已有实例。
- 电脑端每 15 秒检测运行中的播放器和版本，每 60 秒更新安装记录；未知文件版本显示“未知”。没有运行的便携客户端无法通过安装记录发现。版本检测不等于已完成该版本的全部功能适配。
- 客户端音量调节针对应用音频会话；找不到音频进程时明确报错，不会改动整个电脑的系统音量。部分商店客户端可用命令行的 `--audio-process 实际进程名.exe` 指定音频进程。

## 网络与数据

电脑使用 TCP 8765 接收控制，UDP 8766 回复发现请求，同时每 2 秒向手机监听的 UDP 8767 广播在线信号。手机主动搜索与被动监听并用；断线后自动重试，优先使用最近地址。访客网络、AP 隔离、VPN 或防火墙可能阻止发现，手动 IP 可作为备用。

广播只包含电脑名称、稳定标识和端口，不含配对码和授权密钥。配对码只用于第一次认证，后续使用每部手机的随机密钥；有错误配对限流。当前版本使用局域网明文通信，适用于可信家庭局域网，不提供抵御恶意网络监听和中间人攻击的 TLS 保护。

电脑数据位于 `%LOCALAPPDATA%/BiliGestureRemote`：`trust.json` 保存授权，`settings.json` 保存设置，`remote.log` 保存错误日志，`browser-profile` 保存专用播放窗口的浏览器数据。日志最多 3 个、每个 256 KiB。浏览器自动控制端口只绑定本机回环地址，使用系统随机端口。

安装版可从软件设置或 Windows“已安装的应用”卸载。卸载会停止程序及专用播放窗口、删除程序文件和快捷方式、清除启动项与安装登记、清除设置、授权、日志和专用浏览器数据。不会删除哔哩哔哩客户端或平时使用的浏览器数据。防火墙规则清理可能需要管理员授权；拒绝时会明确提示，静默卸载写入日志。

旧版浏览器扩展已不再需要，可以在浏览器扩展页移除。

## 开发与验证

当前开发环境为 Python 3.12 / Windows。常用命令：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
node --test tests/*.test.cjs
.\.venv\Scripts\python.exe scripts/smoke_gui.py
.\.venv\Scripts\python.exe run_desktop.py
```

Android Studio 可打开 `android` 工程；也可运行 `python scripts/build_apk.py`，工具下载至 `.tooling`。两种构建方式均使用 `android/signing/app.keystore` 的原开发签名，并核对已发布证书指纹。首次运行脚本可从旧 `.tooling/debug.keystore` 校验后复制原密钥；缺失或不匹配时停止构建，不会自动生成不同密钥。请在工具缓存之外单独备份 `android/signing/app.keystore`，它不提交代码仓库；仅有公开证书指纹无法恢复私钥。后续版本必须保留包名并递增 `versionCode`。

电脑端通过 `scripts/build_desktop.py` 打包，安装包通过 Inno Setup 6 编译：`python scripts/build_installer.py --compiler ISCC.exe完整路径`。商业分发前需确认构建工具许可。`scripts/smoke_installer.py` 使用独立测试身份验证安装、启动和卸载，不卸载正式电脑端。`scripts/smoke_upgrade.py --baseline 旧版备份目录` 使用独立身份执行旧版安装、运行中覆盖、授权重连、设置与浏览器资料保留、自启状态保留、同版本修复、阻止降级和升级后干净卸载；基线目录应含原版 `BiliRemote.iss` 与 `BiliRemote-Desktop.exe`。`scripts/verify_apk_upgrade.py 旧版.apk 新版.apk` 校验安卓更新包的应用身份、签名与版本代码。

图标源文件位于 `desktop/assets` 与 `android/artwork`；绘制脚本为 `scripts/draw_icon.py`、`scripts/draw_android_icon.py`，仅绘图时需要 Pillow。Android 提供自适应图标和 Android 13 单色图标，电脑程序使用原生托盘。

测试覆盖真实无头 Edge/Chrome 中的视频控制、配对/重连、广播、手势和电脑操作反馈。实体 Android WiFi、多品牌系统及各版哔哩哔哩客户端仍需实机兼容验证。
